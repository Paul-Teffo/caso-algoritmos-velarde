# analisis-optimizacion-algoritmos-examenes
Caso de estudio enfocado en el análisis, diseño y optimización de algoritmos aplicados a un simulador de exámenes. Se busca identificar ineficiencias en la navegación entre preguntas y seguimiento del progreso, mediante la comparación de algoritmos tradicionales y optimizados, rendimiento y escalabilidad ante múltiples participantes simultáneos.
